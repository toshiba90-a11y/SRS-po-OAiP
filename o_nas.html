О нашем учебном портале

Этот сайт создан как итоговый проект по веб-разработке с применением сетки и компонентов Bootstrap 5.

Главная цель портала — собрать в одном месте понятные материалы для начинающих разработчиков, показать примеры адаптивной верстки и научиться правильно структурировать многостраничные сайты.

Используемые технологии:

  • HTML — семантическая разметка страниц
  • CSS — кастомное оформление карточек и цветов
  • Bootstrap — адаптивная сетка, меню, формы и модальные окна
